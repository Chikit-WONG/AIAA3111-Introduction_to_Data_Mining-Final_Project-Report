## Overleaf

## Source ownership

The reviewed local version has **10 pages of main text**, with the discussion ending at the normal bottom of page 10. Disclosures/references and two appendices follow (13 pages total). This uses 11-point text and 21 mm margins. Recheck pagination after changing prose or the TeX engine.

The manuscript includes an abstract, research questions and related work, a vector method overview, an observability decomposition, and a fuller discussion of policy sensitivity and validity. The contribution remains a reproducible empirical study; the report does not claim a new mining algorithm or confirmed retail utility. LaTeX embeds vector PDFs; editable SVGs and PNG previews accompany them.

The evidence snapshot includes report_diagnostics.json, recording explicitly post-hoc rule-overlap and evaluation-confidence diagnostics. These preserve the original 71-rule cohort and do not revise the validation selection.

- `main.tex`, `sections/`, `references.bib`: collaboratively editable manuscript.
- `generated/`: values and tables generated by the code repository.
- `figures/`: rendered analysis figures generated by the code repository.
- `evidence/`: compact CSV/JSON evidence snapshot and SHA-256 export manifest.
- `build/`, `Report.pdf`: local previews, ignored by Git.

The exporter replaces its generated tables, figures and evidence only. It does not overwrite the manuscript sections. After changing experimental settings, review the prose as well as the updated numbers: some interpretations and illustrative values are deliberately written as narrative.

For a local build, use `latexmk -pdf main.tex`, or run `scripts/build_report.ps1` from the code repository after installing its portable Tectonic helper. The initial Tectonic build downloads its TeX packages; subsequent builds reuse a local cache.

## Review and submission

The main text flows continuously: no main-text section forces a new page. Figure and table placement permits text to fill the available page area. Disclosures/reference material and the start of the appendices retain explicit page boundaries; Appendices A and B now flow continuously. The appendices include the recorded execution environment, reproducibility instructions and audit evidence. The font size, line spacing and page margins were not enlarged to fill pages.

After a local build, run the code repository's scripts/check_report_layout.py with its Python environment. It checks for 10 main-text pages, flags more than 8 mm of extra space above the normal bottom margin on both main-text and back-matter pages, and requires page 10 to end within 1 mm of that margin. Results are written to build/layout_check.json. Rendered-page inspection remains necessary for chart labels, overlaps and reading order.

The course requires 6-10 pages of main text including figures and tables, excluding Disclosures, references and appendix. The disclosure section identifies extensive Codex assistance.
